# HR Systems

Учебный проект для изучения Python, ООП и SQLite.

**Статус:** Alpha 0.7.1 (первый рабочий релиз)

---

## Возможности

- Полное управление отделами (CRUD)
- Полное управление должностями (CRUD)
- Полное управление сотрудниками (CRUD)
- Полное управление проектами (CRUD)
- Назначение сотрудников на проекты (связь многие-ко-многим)
- Консольный интерфейс (CLI)

---

## Структура проекта
HR_Systems/
├── docs/              — документация
├── uml/               — UML-диаграммы
├── db/                — база данных (SQLite)
├── src/               — исходный код (в будущем)
├── tests/             — тесты
├── main.py            — точка входа
├── db_manager.py      — работа с базой данных
├── models.py          — модели сущностей
├── CHANGELOG.md
├── status.md
└── README.md
