# HR Systems

Учебный проект для изучения Python, ООП и SQLite.

Статус: **Alpha 0.7.0**

## Возможности
- управление сотрудниками
- управление отделами
- управление должностями
- управление проектами

## Установка
1. Создать виртуальное окружение
2. Активировать его
3. Запустить проект через main.py (будет позже)

## Структура проекта
docs/ — документация  
uml/ — диаграммы  
db/ — база данных  
src/ — исходный код  
tests/ — тесты
