# **Database Design**

## **1. Entities (Сущности)**

### **Employee**  
Сотрудник компании. Имеет имя, возраст, принадлежит к отделу и должности. Может участвовать в нескольких проектах.

### **Department**  
Отдел компании. Содержит название и список сотрудников.

### **Position**  
Должность сотрудника. Содержит название и базовую зарплату.

### **Project**  
Проект компании. Имеет название, описание и список сотрудников, участвующих в проекте.

### **DatabaseManager**  
Класс, отвечающий за работу с SQLite: подключение, выполнение запросов, CRUD‑операции.

---

## **2. Tables (Таблицы)**

### **departments**
| Поле | Тип | Описание |
|------|------|----------|
| id | INTEGER, PK | Уникальный идентификатор отдела |
| name | TEXT | Название отдела |

---

### **positions**
| Поле | Тип | Описание |
|------|------|----------|
| id | INTEGER, PK | Уникальный идентификатор должности |
| name | TEXT | Название должности |
| salary | INTEGER | Базовая зарплата |

---

### **employees**
| Поле | Тип | Описание |
|------|------|----------|
| id | INTEGER, PK | Уникальный идентификатор сотрудника |
| name | TEXT | Имя сотрудника |
| age | INTEGER | Возраст |
| department_id | INTEGER, FK → departments.id | Отдел |
| position_id | INTEGER, FK → positions.id | Должность |

---

### **projects**
| Поле | Тип | Описание |
|------|------|----------|
| id | INTEGER, PK | Уникальный идентификатор проекта |
| name | TEXT | Название проекта |
| description | TEXT | Описание проекта |

---

### **employee_projects** (связь многие‑ко‑многим)
| Поле | Тип | Описание |
|------|------|----------|
| employee_id | INTEGER, FK → employees.id | Сотрудник |
| project_id | INTEGER, FK → projects.id | Проект |

---

## **3. Relations (Связи)**

- **Department → Employees** — один ко многим  
- **Position → Employees** — один ко многим  
- **Employee ↔ Project** — многие ко многим через `employee_projects`  
- **Employee → Department** — многие к одному  
- **Employee → Position** — многие к одному
