# 🏗️ **HR Systems — Обзор проекта**

## 📌 Описание  
HR Systems — учебный проект для изучения Python, ООП и SQLite.  
Цель — создать простую, но расширяемую HR‑систему, похожую на реальные корпоративные решения.

Проект развивается постепенно: от настройки окружения до полноценной системы управления сотрудниками, отделами и проектами.

---

## 🧭 1. Настройка окружения  
Перед началом разработки необходимо:

- установить Python 3.12+  
- установить VS Code  
- установить расширение Python  
- создать виртуальное окружение `venv`  
- активировать его  
- установить SQLite Browser (по желанию)  
- создать структуру папок проекта  

Структура проекта:

```
HR_Systems/
 ├── docs/
 ├── uml/
 ├── db/
 ├── src/
 └── tests/
```

---

## 🧱 2. Основные сущности проекта  
Проект включает следующие ключевые сущности:

- Employee — сотрудник  
- Department — отдел  
- Position — должность  
- Project — проект  
- DatabaseManager — работа с SQLite  

---

## 🧩 3. Структура базы данных  
Проект использует несколько таблиц:

- employees  
- departments  
- positions  
- projects  
- employee_projects (связь многие‑ко‑многим)

Это нормальная структура для HR‑системы, где сущности связаны между собой.

---

## 🔗 4. Связи между сущностями  
- Employee → Department (многие к одному)  
- Employee → Position (многие к одному)  
- Employee ↔ Project (многие ко многим)  
- Department → Employees (один ко многим)  
- Project → Employees (через таблицу‑связку)  

---

## 🧠 5. ООП‑механика  
- Композиция: Employee содержит Department и Position  
- Композиция: Project содержит список Employees  
- Инкапсуляция: скрытие деталей работы с БД  
- Наследование появится позже (например, Manager → Employee)
